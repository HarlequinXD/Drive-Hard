# Drive Hard — Windows Edition

A PS1-inspired open-world driving and exploration game for Windows, using the original CPU software renderer and procedural world simulation.

See [README-WINDOWS.md](README-WINDOWS.md) for GitHub upload, automatic EXE builds, and Xbox/keyboard controls.

The game engine lives under `app/src/main/java/com/harlequinxd/drivehard/core/`; the Windows launcher and XInput controller integration live under `app/src/main/java/com/harlequinxd/drivehard/desktop/`.

Build automation: `.github/workflows/build-windows.yml`. No Android APK workflow is included.
